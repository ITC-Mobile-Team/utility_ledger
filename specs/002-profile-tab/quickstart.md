# Quickstart: перевірка табу «Профіль»

## Передумови

- Development build уже встановлений у iOS Simulator (нових нативних модулів фіча не додає — перезбирати не треба).
- Metro запущений: `npx expo start`.
- Користувач увійшов (Apple) і має хоча б одну адресу з місяцем.

## 1. Статичні перевірки

```bash
npx expo lint
```

```bash
npx tsc --noEmit
```

Очікування: обидві без помилок.

## 2. Сценарій ui-check

```bash
.claude/skills/ui-check/scripts/ui run .claude/skills/ui-check/flows/profile.flow
```

`profile.flow` проходить: таб «Профіль» (`check role=tab&label=Профіль value=1`, `wait id=profile.screen`) → `tap id=profile.card` → `wait id=editName.screen` → ввести нове імʼя (`keys`, латиницею — обмеження HID) → `tap id=editName.save` → `see <нове імʼя>` → `tap id=profile.privacy` → `wait id=privacy.screen` → `tap id=navigationBar.back` → те саме для `profile.terms`. Очікування: усі кроки `ok`.

Також оновлений `smoke.flow` (`open /profile`, `check role=tab&label=Профіль value=1`) — усі кроки `ok`.

## 3. Ручні перевірки

| Що | Як | Очікування |
|---|---|---|
| Збереження імені (SC-002) | змінити імʼя, повністю закрити й відкрити застосунок | нове імʼя в картці й рядку «Імʼя» |
| Спосіб входу | вийти, увійти через Google | рядок «Google-акаунт · вхід без пароля», іконка Google, імʼя від провайдера |
| Сповіщення (SC-004) | увімкнути в профілі → відкрити «Світло» → налаштування | там перемикач увімкнений; і навпаки |
| Відмова в дозволі | заборонити сповіщення в Параметрах, увімкнути перемикач | лишається вимкненим, `Alert` з «Параметри» |
| Вийти (SC-003) | «Вийти» → підтвердити, увійти знову | онбординг, порожні «Обʼєкти», налаштування «Світла» порожні |
| Видалити акаунт (SC-003) | те саме через «Видалити акаунт» | те саме |
| Перерване стирання | підтвердити «Видалити акаунт» і одразу вбити застосунок (`xcrun simctl terminate`) | після запуску — перший екран, після входу даних немає |
| Темна тема (SC-001) | перемкнути симулятор у dark | екрани відповідають темним токенам |
| Відповідність макету (SC-001) | скриншоти 16, 16a, 16b, 16c, 17, 18, 19 | збігаються з оновленими артбордами |
| «Ще» зникло (SC-005) | `grep -rn "«Ще»\|label=Ще\|'Ще'" src .claude/skills/ui-check docs` | порожньо |
