# Quickstart: перевірка фічі

## Підготовка

```bash
npx expo start
```

Застосунок у iOS Simulator (dev build або Expo Go — нових нативних модулів немає). Для сценаріїв ui-check — скіл `ui-check` з `.claude/skills/ui-check/flows/`.

## US1 — тема

1. Чистий стан: профіль → рядок «Тема» показує «Як у системі». Перемкнути тему симулятора (Settings → Developer → Dark Appearance) — застосунок іде за нею без перезапуску.
2. «Тема» → «Темна» при світлій системі: перехід плавний (до 0,5 с), картка «Темна» позначена, екран лишився відкритим.
3. Обійти всі вкладки, відкрити діалог «Вийти з акаунта?» (і скасувати), клавіатуру на «Ваше імʼя», перемикач сповіщень — усе темне, рядок стану світлий текстом. Повторити для «Світла» при темній системі.
4. Закрити застосунок і запустити знову — одразу темний, без білого кадру.
5. VoiceOver на картці: «Темна, вибрано, перемикач» (або еквівалент для radio).
6. Швидко торкнутися «Світла» → «Темна» → «Як у системі» — лишається «Як у системі».

## US2 — статус «Світла»

1. Чистий стан: профіль → «Сповіщення» показує «Місто й черги не налаштовані» і «Налаштувати».
2. «Налаштувати» → активний таб «Світло», відкрито налаштування; «Назад» → головний екран «Світла».
3. Вибрати Київ (без постачальника) → у профілі «Постачальник для вашого міста ще не доданий».
4. Вибрати місто з постачальником без черг → «Черги не вибрані»; вибрати чергу → статус зник одразу після повернення на «Профіль».

## US3 — правки профілю

1. Дотик до картки профілю — нічого не відкривається, стрілки немає.
2. Рядок «Імʼя» — без підпису, відкриває «Ваше імʼя».
3. Відступ «Документи» → «Вийти» удвічі більший, ніж між розділами (звірити з артбордом 16).

## Стирання

1. Вибрати «Темна» → «Вийти» → підтвердити: застосунок повертається на вхід у системній темі; після нового входу «Тема» — «Як у системі».
