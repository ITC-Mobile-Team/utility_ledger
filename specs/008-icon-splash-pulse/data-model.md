# Data Model: Іконка застосунку, splash з анімацією та пульсація порожніх станів

Фіча не додає даних користувача й нічого не зберігає (ні у Firestore, ні в `KeyValueStorage`). Нижче — ресурси й стани в памʼяті, з яких складається рішення.

## Стан анімованого splash (у памʼяті)

```text
           монтування накладки (провайдери готові)
                         │  onLayout → SplashScreen.hide()
                         ▼
   ┌──────────── visible (анімація, таймери від t0) ────────────┐
   │ minElapsed = t ≥ 1000 мс                                    │
   │ dataReady  = !isSignedIn || status ≠ 'loading' || t ≥ 3000  │
   └───────────────┬────────────────────────────────────────────┘
                   │ minElapsed && dataReady
                   ▼
              fading (opacity → 0 за 300 мс, pointerEvents none)
                   │
                   ▼
              finished (накладка знята; splashFinished = true до кінця процесу)
```

- `splashFinished` — модульний прапорець; повторні монтування (перемонтування під `AccountDataProvider` при вході/виході) одразу рендерять `null`.
- Холодний запуск = новий JS-процес → прапорець `false`.

## Анімаційні параметри

| Анімація | Параметр | Значення | Джерело |
|---|---|---|---|
| Сонце splash | `p` | 0 → 1 → 0, 7000 мс у кожен бік, `inOut(ease)` | `Splash.dc.html` `sp-sun` |
| | зсув | `x = −170 + 340·p`, `y = 40 − 100·sin(π·p)` | ключові кадри (−170,40) → (0,−60) → (170,40) |
| Тінь splash | поворот | `−38° + 76°·p`, точка обертання — верх тіні під знаком | `sp-cast` |
| Кільця пульсації | масштаб / прозорість | `.55 → 1.35` / `.9 → 0`, 2800 мс, `out(ease)`, друге кільце +1400 мс | `ui.css` `ring-pulse` |
| Плитка пульсації | масштаб | `1 → 1.06 → 1`, 2800 мс, `inOut(ease)` | `ui.css` `core-pulse` |
| Зменшити рух | усі | splash: `p = 0.5` статично; пульсація: кілець немає, плитка 1 | `ui.css` `prefers-reduced-motion` |
