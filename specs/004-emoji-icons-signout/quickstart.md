# Quickstart: перевірка фічі

## Передумови

- Запущений dev-сервер (`bunx expo start` або `npx expo start`), застосунок у iOS Simulator; для Android — Pixel-емулятор.
- Нова development build не потрібна (нативних змін немає).
- Скіл `ui-check` для сценаріїв і обрізаних скріншотів.

## 1. Вихід не стирає даних (US2)

1. Увійти, пройти онбординг, додати обʼєкт «Тест», вибрати тему «Темна» і стартову вкладку «Світло».
2. «Профіль» → рядок «Вийти»: під заголовком немає підпису. Натиснути, і в діалозі «Вийти з акаунта?» немає тексту про стирання. Натиснути «Вийти».
3. **Очікується**: екран входу; тема лишилась темною.
4. Увійти знову (той самий або інший спосіб входу). **Очікується**: онбординг не показується, відкривається вкладка «Світло», обʼєкт «Тест» на місці.
5. Повторити кроки 2–4 з «Видалити акаунт»: у діалозі текст «Поки що це лише вихід з акаунта…», результат той самий.
6. Сценарій: `ui-check` → `flows/sign-out.flow` (новий), `flows/profile.flow`.

## 2. Emoji-іконки (US1)

1. Пройти екрани: вхід і помилка входу, онбординг (3 кроки), «Обʼєкти» (порожній і заповнений), обʼєкт, місяць, показник, сума з рахунку, розрахунок, послуги, форма послуги, піка іконки, «Світло» і його налаштування, «Профіль», «Тема».
2. **Очікується**: кожна іконка поза таб-баром — emoji, включно з шевронами (▶️), галочками (✅), «➕/➖», «↗️», «↕️». Векторними лишаються лише таб-бар, логотипи Google/Apple і стрілка «Назад».
3. Порівняти однакові ролі: усі іконки в колах рядків профілю й кнопок навбару — один розмір; усі шеврони — один розмір.
4. Збільшити розмір шрифту системи до максимального → іконки не змінили розміру.

## 3. Центрування ±1 pt

1. `ui-check` → обрізаний скріншот кола `RowIcon`, плитки послуги, кнопки навбару й степера «➕/➖» на iOS і Android, у світлій і темній темі.
2. Скриптом у scratchpad порахувати рамку непрозорих пікселів emoji в контейнері: |лівий − правий| ≤ 1 pt, |верхній − нижній| ≤ 1 pt.
3. Якщо ні — підкоригувати платформні `k`/`translateY` в `EmojiGlyph` і повторити.

## 4. Наостанок

```bash
npx expo lint
```

```bash
npx tsc --noEmit
```

Обидві команди завершуються без помилок. Канвас (`docs/design.md`) звірено: артборди з іконками й 16/16b/16c оновлені.
