# UI Contract: `NavigationView` і навбар

Внутрішній інтерфейс, яким користуються екрани в `src/app/`. Зовнішніх API фіча не має.

## Пропси `NavigationView`

| Проп | Було | Стає |
|---|---|---|
| `type` | `'full' \| 'short'` | без змін |
| `barType` | колір навбару | без змін; кольоровий навбар (`!== 'transparent'`) завжди має шторку |
| `title`, `subtitle`, `headerAccessory`, `headerContent`, `headerTrailing` | — | без змін |
| `navigationBarButtons`, `onNavigationButtonPress` | великі кнопки + короткі «пігулки» під час скролу | лише великі кнопки; ховаються разом із великим блоком |
| `cornerRadius` | радіус шторки, задає кожен екран | **прибрано**; радіус — `SHEET_RADIUS` (28), правило в `NavigationView` |
| `contentInsets.top` | 0 / 16 / 20 / 24 / нічого | **прибрано**; відступ до першого блоку — `SHEET_CONTENT_TOP` (24) під шторкою |
| `contentInsets.horizontal` | 20 / 24 / нічого | за замовчуванням 20; передається лише для контенту на всю ширину (`0`) |
| `contentInsets.bottom` | за екраном | без змін |
| `refreshControl` | — | без змін для екрана; `NavigationView` сам зсуває індикатор під навбар |

## Експорти `src/components/navigation-bar/index.ts`

- Прибирається `ShortNavigationBarButton`.
- Нові константи в `constants.ts`: `SHEET_RADIUS = 28`, `SHEET_CONTENT_TOP = 24`.
- Прибираються `COLLAPSE_DISTANCE`, `SHORT_ROW_OFFSET`, `SHORT_ROW_BOTTOM`.

## Поведінка (гарантії для кожного екрана)

1. Один прогрес згортання на весь навбар; заголовок, кнопки, градієнт і кути шторки завершують згортання одночасно.
2. Прогрес — функція положення контенту, не напрямку скролу.
3. Після жесту навбар повністю розгорнутий або повністю згорнутий; доводка — до ближчого стану (межа `D/2`), після зупинки, один раз.
4. Нове торкання скасовує доводку.
5. Відскок не змінює навбар.
6. Кути шторки: `p × 28` на екранах зі згортанням, 28 без згортання.
7. Бічне поле 20, відступ від шторки до першого блоку 24.
8. Кожна дія навбару в дереві доступності й у UI-перевірках (testID) рівно один раз.

## testID

Без змін для великих кнопок (`docs/patterns/test-ids.md`). Короткі «пігулки» більше не існують, тож testID прихованого ряду зникають із дерева.
