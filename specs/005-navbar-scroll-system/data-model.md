# Data Model: стан навбару

Фіча не зберігає даних: немає сховища, мережі чи міграцій. Нижче — модель стану UI, яку ділять `NavigationView` і `ThemedNavigationBar`. Усі значення — shared values Reanimated, а у воркетах до них звертаються лише через `get()`/`set()` (`docs/patterns/reanimated.md`).

## Величини

| Назва | Що це | Звідки |
|---|---|---|
| `H` | Висота розгорнутої накладки навбару: safe area зверху + рядок «назад» + великий блок + смужка шторки | `onLayout` накладки, максимум |
| `L` | Висота великого блоку: заголовок, підзаголовок, `headerContent`, `headerTrailing`, ряд великих кнопок | `onLayout` блоку, максимум |
| `D` | Відстань згортання: `L` (+ рядок короткого заголовка, якщо немає кнопки «назад»); 0 для навбару без великого блоку | похідна від `L` |
| `scrollY` | Нормалізований зсув контенту: 0 — верх контенту на обох платформах | обробник скролу |
| `maxScrollY` | Найбільший зсув з урахуванням нижнього інсету | обробник скролу |
| `keyboard` | 0…1, анімується з клавіатурою; лише для екрана у фокусі | `useKeyboardHandler` |
| `p` | Прогрес згортання `clamp(max(scrollY, keyboard × D) / D, 0, 1)`; 0, якщо `D = 0` | похідна |

## Що виводиться з `p`

| Елемент | Розгорнутий (`p = 0`) | Згорнутий (`p = 1`) | Як |
|---|---|---|---|
| Накладка (заголовок, кнопки, градієнт) | на місці | зсунута вгору на `D` | `translateY = −p × D` |
| Рядок «назад» і короткий заголовок | на місці | на місці | контрзсув `+p × D` |
| Великий заголовок і кнопки | видимі | прозорі | `opacity` 1 → 0 на `p ∈ [0, 0.7]` |
| Короткий заголовок | прозорий | видимий | `opacity` 0 → 1 на `p ∈ [0.6, 1]` |
| Кути шторки | 0 | 28 | `p × SHEET_RADIUS`; без згортання — завжди 28 |
| Натискання й доступність ряду кнопок | увімкнені | вимкнені | поріг `p ≥ 0.5` → `pointerEvents='none'`, схований від VoiceOver/TalkBack |

## Стани й переходи

```text
          скрол / інерція (p стежить за scrollY)
 Розгорнутий ───────────────────────────────► Згорнутий
   p = 0     ◄───────────────────────────────   p = 1
                │                       ▲
                ▼                       │
          Проміжний (0 < p < 1) ── лише під час руху
                │
     зупинка ───┤ y < D/2 → доводка до 0
                └ y ≥ D/2 → доводка до D
     нове торкання → доводка скасовується, p знову стежить за пальцем
     відкрита клавіатура → p = 1 незалежно від scrollY
```

Правила:
- Після будь-якого жесту `p ∈ {0, 1}` (FR-008).
- Відскок (`scrollY < 0` або `> maxScrollY`) не виводить `p` за `[0, 1]` (FR-007).
- Доводка запускається не більше одного разу на зупинку (FR-004).

## Розпірка й вимкнений скрол

- `contentFits`: кінець контенту + нижній інсет ≤ висота вʼюпорту. Перевіряється лише нагорі і не перемикається посеред жесту; з `refreshControl` скрол увімкнений завжди.
- Розпірка під контентом: `max(0, D − maxScrollY без розпірки)`, лише коли скрол увімкнений.
