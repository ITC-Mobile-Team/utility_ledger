# Quickstart: перевірка фічі 014

## Передумови

- Dev server: `npx expo start`, iOS Simulator / Android-емулятор з наявною development build — нова не потрібна.
- Акаунт з будь-яким обʼєктом; інтернет.

## 1. Розбір відповіді (без UI)

Зберегти відповідь `curl -s --compressed https://svitlo-proxy.svitlo-proxy.workers.dev/ > sp.json` і прогнати `parseSvitloRegion` разовим скриптом для `kyiv`, `lvivska-oblast`, `chernivetska-oblast`, `mikolaivska-oblast`:

- Київ: 60 черг, у кожного дня 48 слотів; завтра без графіка → дня немає в `days`.
- Львів (зараз усі `0`) → `days: []`, без помилки.
- Чернівці: черги `1`…`12`.
- Миколаїв: слоти з кодом `3` → `maybe`.

## 2. Шторка міст

Профіль / налаштування графіка → «Місто»: у «Доступно» 23 міста, у «Незабаром» лише Херсон.

## 3. Місто на svitlo-proxy

1. Обрати «Київ» → під карткою міста підпис «Дані: svitlo.live, не офіційне джерело — звіряйте з сайтом обленерго»; сітка 60 черг 1.1…60.1.
2. Обрати черги 1.1 і 30.1, зберегти → вкладка «Світло»: підзаголовок «ДТЕК Київські електромережі · перевірено о HH:MM», графік на сьогодні.
3. Перемкнутися на «Завтра» до оголошення графіка → «Графік на завтра ще не опубліковано».
4. Обрати «Львів» (дні без даних) → обидва дні «не опубліковано», помилки й «Спробувати ще раз» немає.
5. Протягом 2 хв перемкнути місто Київ → Харків → Київ: у мережевих логах один запит до svitlo-proxy (SC-005).
6. Потягнути вниз → новий запит, час «перевірено о» змінюється.
7. Вимкнути мережу, перезапустити застосунок → збережений графік з приміткою «показано збережений».

## 4. Звірка з офіційними графіками (користувач)

Для кожного міста, яке перевіряєте: обрати місто й чергу, порівняти проміжки вимкнень на сьогодні з сайтом обленерго («Не знаєте свою чергу?» відкриває його). Окремо — Миколаїв: що на сайті в слотах, які в застосунку «можливе вимкнення».

## 5. Полтава без змін

Обрати «Полтава», черга 1.1 → підзаголовок «Полтаваобленерго · оновлено о …», проміжки перемикання як на poe.pl.ua, підпису про svitlo.live немає.
