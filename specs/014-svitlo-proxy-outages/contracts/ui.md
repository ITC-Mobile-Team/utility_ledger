# Contract: UI

Тексти й умови показу. Дизайн наявних елементів не змінюється; артборди — у [plan.md](../plan.md).

## Шторка вибору міста (`outage-city-sheet.tsx`)

- «Доступно»: усі міста, для яких `getProviderForCity` повертає постачальника — 23 міста.
- «Незабаром»: Херсон.
- Під назвою міста — `provider.name` (назва обленерго), як зараз для Полтави.

## Налаштування графіка (`(outages)/outage-settings.tsx`)

- Блок міста: підпис `provider.name` (без змін).
- **Нове**: якщо `provider.dataSource` є — під карткою міста підпис шрифтом `footnote`, колір `muted`, стиль `styles.help` (як інші підказки екрана):
  «Дані: svitlo.live, не офіційне джерело — звіряйте з сайтом обленерго»
  `testID='outageSettings.dataSource'`. Для POE підпису немає.
- «Мої черги»: сітка `QueueToggle` з усіма `provider.queues` у порядку конфігурації (для Києва 60 чипів, сітка переноситься в рядки; висота екрана росте, скрол — наявний).
- «Не знаєте свою чергу?» → `provider.lookupUrl`, підпис «Перевірте адресу на сайті {provider.name}» (без змін).

## Вкладка «Світло» (`(outages)/index.tsx`)

- Підзаголовок навбару:
  - під час запиту — «{name} · оновлюємо…» (без змін);
  - `schedule.updatedLabel` є — «{name} · оновлено о HH:MM» (POE, без змін);
  - інакше — «{name} · перевірено о HH:MM», час `fetchedAt` у `provider.timeZone`.
- День без даних для обраної черги — наявний стан «Графік на сьогодні не опубліковано» / «Графік на завтра ще не опубліковано» (артборд 20b). Не помилка, без «Спробувати ще раз».
- Попередження перед вимкненням на день без даних не плануються (у `days` цього дня/черги немає).
