# Дизайн

Макети всіх екранів: https://claude.ai/artifact/Px8EEBtJf8LRD97UwbGUjj

Це канвас Claude Design. Читати його через інструмент Artifact (`action: "read"`), не через WebFetch:

- `project/canvas.json` — індекс артбордів (`boards`): назва екрана в `title`, файл — ключ;
- `project/<Екран>.dc.html` — розмітка й дані одного артборда;
- `project/ui.css` — спільні стилі й токени (кольори світлої та темної теми, радіуси, класи `.receipt`, `.dash`, `.row-sub` тощо).

Посилання з `#artboard-<id>` веде на конкретний артборд; файл шукай за назвою екрана в `canvas.json`.

Перед версткою або перевіркою екрана відкрий відповідний артборд і звір відступи, шрифти й кольори з `ui.css`.
