# Патерни застосунку

Домовленості, як у проєкті зроблені типові речі. Перед роботою над схожим екраном прочитай відповідний файл і зроби так само. Коли узгоджуємо новий патерн або змінюємо наявний — оновлюй файл тут.

- [Клавіатура на екранах з полями](keyboard.md) — фокус, закриття клавіатури, футер над клавіатурою, шторки зі списками
- [Екрани вибору](pickers.md) — повноекранний вибір значення як екран стеку з поверненням через `dismissTo`; вибір місяця — шторка з сіткою 3×4; вибір теми — миттєве застосування на екрані, картки зі сценою логотипу без галочки; короткий вибір (стартова вкладка, стартова черга) — нативне меню від рядка
- [Кнопки навбару](navigation-bar-buttons.md) — великі кнопки під заголовком: ширина 50% екрана, один ряд з горизонтальним скролом, ховаються разом із заголовком (без «пігулок»)
- [Заголовок навбару при скролі](navigation-bar-title.md) — однакові шрифти заголовка (28/22) на всіх екранах, без індикаторів прокрутки; навбар-накладка над скролом, один прогрес згортання трансформаціями, кути шторки 28 і відступ 24 задає NavigationView
- [Таб-бар](tab-bar.md) — кольори дизайн-системи на Android; видно лише на кореневих екранах табів, вкладені екрани «Обʼєктів» без нього; стартова вкладка при холодному запуску; перехід в екран іншого табу
- [Свайп-дії та скидання](swipe-actions.md) — свайп уліво з деструктивною дією, підтвердження через `Alert`, тост «Повернути»
- [Введення показника](meter-reading.md) — барабан за форматом послуги (світло 5/2, вода 6/3, газ 8/3), показник в одиницях з дробом, введення по цифрі, стани клітинок, підказки й помилка «менше попереднього»
- [Введення суми з рахунку](amount-input.md) — велика сума по центру, клавіатура відкрита одразу, чип «Минулого місяця» і різниця з ним
- [Shared values і React Compiler](reanimated.md) — у воркетах і JS-коді лише `get()`/`set()`, щоб компілятор не читав `.value` під час рендеру
- [Графіки відключень](outage-providers.md) — вкладка «Світло», постачальники за містами, як додати нове місто, стартова черга при холодному запуску
- [Кнопки й повторні тапи](buttons.md) — усі натискання через `Pressable` з `@/components`, глобальний замок 500 мс, `guarded={false}` лише для локального стану
- [Налаштування пристрою](preferences.md) — тема (плавна зміна знімком екрана) і стартова вкладка в `KeyValueStorage`, `PreferencesProvider` читає їх до першого рендеру, виходом не скидаються
- [Профіль і дії з акаунтом](account-actions.md) — вхід через Firebase (Apple, Google, `AuthError` cancelled/failed), дані профілю через `ProfileRepository`, «Вийти» завершує сесію, «Видалити акаунт» спершу видаляє всі дані акаунта, потім акаунт з повторним підтвердженням; вихід дані не стирає
- [Дані користувача](user-data.md) — дані акаунта у Firestore (`users/{uid}/…`), що лишається на пристрої, `setUser` і мутації без очікування сервера, офлайн через кеш SDK, перше завантаження зі скелетонами й «Немає інтернету», перенесення даних попередньої версії, видалення даних; архів обʼєктів (`setObjectArchive`, лише перегляд, «Аналітика» через `getAnalyticsObjects`)
- [Іконки](icons.md) — усі іконки emoji через `AppImage` і шкалу ролей, `EmojiGlyph` центрує гліф, «заповнено» — галочка без підкладки, коло під ➕ — `plusSoft`, виключення: таб-бар, шеврони (`Chevron`), логотипи Google/Apple, стрілка «Назад»
- [Splash і іконка застосунку](splash.md) — системний splash зі знаком, накладка `AppSplash` з анімацією сонця й тіні (цикл `useSunCycle` спільний зі сценами теми) та нативним індикатором, ≥ 1 с, дані акаунта ≤ 3 с, лише холодний запуск; Icon Composer для iOS, адаптивна іконка Android, як перегенерувати PNG з SVG
- [Пульсація порожніх станів](empty-state-pulse.md) — `PulseRings` + `PulseCore` з `@/components`, кольори кілець за станом, кільця під колами ілюстрації, вимикається поза фокусом і при «Зменшити рух»
- [testID для UI-перевірок](test-ids.md) — схема `екран.компонент.елемент`, індекс для списків, testID на `Pressable` і на видимому блоці прихованих інпутів; як передати його в спільні компоненти; ряд кнопок навбару `navigationBar.buttons` гортається кроком `drag`
- [Центрований текст](centered-text.md) — блок заголовка й опису по центру розтягнутий на всю ширину (`align='stretch'` + `textAlign`), щоб на Android після зміни теми заголовок з від’ємним `letterSpacing` не переносився з обрізаним другим рядком
