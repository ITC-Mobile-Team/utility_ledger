# Патерни застосунку

Домовленості, як у проєкті зроблені типові речі. Перед роботою над схожим екраном прочитай відповідний файл і зроби так само. Коли узгоджуємо новий патерн або змінюємо наявний — оновлюй файл тут.

- [Клавіатура на екранах з полями](keyboard.md) — фокус, закриття клавіатури, футер над клавіатурою, шторки зі списками
- [Екрани вибору](pickers.md) — повноекранний вибір значення як екран стеку з поверненням через `dismissTo`; вибір місяця — шторка з сіткою 3×4; вибір теми — миттєве застосування на екрані; короткий вибір — нативне меню від рядка
- [Кнопки навбару](navigation-bar-buttons.md) — великі кнопки під заголовком: ширина 50% екрана, один ряд з горизонтальним скролом, ховаються разом із заголовком (без «пігулок»)
- [Заголовок навбару при скролі](navigation-bar-title.md) — навбар-накладка над скролом, один прогрес згортання трансформаціями, кути шторки 28 і відступ 24 задає NavigationView
- [Таб-бар](tab-bar.md) — видно лише на кореневих екранах табів, вкладені екрани «Обʼєктів» без нього; стартова вкладка при холодному запуску; перехід в екран іншого табу
- [Свайп-дії та скидання](swipe-actions.md) — свайп уліво з деструктивною дією, підтвердження через `Alert`, тост «Повернути»
- [Введення показника](meter-reading.md) — барабан лічильника з введенням по цифрі, стани клітинок, підказки й помилка «менше попереднього»
- [Введення суми з рахунку](amount-input.md) — велика сума по центру, клавіатура відкрита одразу, чип «Минулого місяця» і різниця з ним
- [Shared values і React Compiler](reanimated.md) — у воркетах і JS-коді лише `get()`/`set()`, щоб компілятор не читав `.value` під час рендеру
- [Графіки відключень](outage-providers.md) — вкладка «Світло», постачальники за містами, як додати нове місто
- [Кнопки й повторні тапи](buttons.md) — усі натискання через `Pressable` з `@/components`, глобальний замок 500 мс, `guarded={false}` лише для локального стану
- [Налаштування пристрою](preferences.md) — тема і стартова вкладка в `KeyValueStorage`, `PreferencesProvider` читає їх до першого рендеру, виходом не скидаються
- [Профіль і дії з акаунтом](account-actions.md) — дані профілю через `ProfileRepository` (заміна на Firebase), «Вийти» і «Видалити акаунт» лише завершують сесію (`signOut()`), без стирання даних
- [Іконки](icons.md) — усі іконки emoji через `AppImage` і шкалу ролей, `EmojiGlyph` центрує гліф, виключення: таб-бар, шеврони (`Chevron`), логотипи Google/Apple, стрілка «Назад»
- [testID для UI-перевірок](test-ids.md) — схема `екран.компонент.елемент`, індекс для списків, testID на `Pressable` і на видимому блоці прихованих інпутів; як передати його в спільні компоненти
