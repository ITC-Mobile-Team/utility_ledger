# Центрований текст

Блок центрованого тексту (заголовок і опис порожнього стану, «Адресу додано», «Немає інтернету», повідомлення вкладки «Світло») займає всю ширину батька, а по центру його ставить `align='center'` у `ThemedText` (`textAlign`):

```tsx
<VStack spacing={24} align='center'>        {/* ілюстрація по центру */}
  …
  <VStack spacing={10} align='stretch'>     {/* текст — на всю ширину */}
    <ThemedText font='emptyStateTitle' align='center'>{title}</ThemedText>
    <ThemedText color='muted' align='center'>{message}</ThemedText>
  </VStack>
</VStack>
```

## Чому не `align='center'` у стеку з текстом

Тоді ширину `Text` задає його власний вимір (fit-content). На Android після зміни теми (в застосунку чи системної) жирний Onest з від’ємним `letterSpacing` (`emptyStateTitle` 24/700, −0.48) перевимірюється трохи вужчим, ніж малюється: останнє слово переноситься, а висота лишається на один рядок, тож другий рядок обрізано («Додайте першу» без «адресу»). Коли блок розтягнутий на всю ширину, ширина тексту не залежить від виміру, і на iOS вигляд такий самий.

- Для однорядкових заголовків з від’ємним `letterSpacing` по центру — завжди `stretch` у батька (чи `alignSelf: 'stretch'`), не fit-content.
- Перевірка на Android: емулятор, відкрити екран, змінити тему (Профіль → Тема або `adb shell cmd uimode night yes|no` при темі «Як у системі»), повернутися на екран.
