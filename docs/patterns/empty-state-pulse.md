# Пульсація порожніх станів

Еталон — `ui.css` канвасу, «Pulse — empty / waiting states», і артборди 05a, 08e, 12e, 09e, 20 («Оберіть свою чергу»), 20c, 05o. Від центральної плитки по черзі розходяться два кільця, а сама плитка ледь «дихає».

## Компоненти (`src/components/pulse.tsx`, експорт з `@/components`)

- `PulseRings({ color, size })` — два кола на весь контейнер ілюстрації: `scale .55 → 1.35`, `opacity .9 → 0`, 2,8 с, `out(ease)`, нескінченно; друге — зі зсувом 1,4 с.
- `PulseCore` — обгортка центральної плитки: `scale 1 → 1.06 → 1` за 2,8 с, `inOut(ease)`.
- `usePulseActive()` — `useIsFocused()` && `!useReducedMotion()`. Неактивний: `PulseRings` рендерить `null`, `PulseCore` повертає масштаб 1 і скасовує анімацію.

Анімуються лише `transform` і `opacity` на UI-потоці — розмітка сусідів не змінюється. Shared values — через `get()/set()` ([reanimated.md](reanimated.md)).

## Кольори кілець

| Стан | Артборд | `color` |
|---|---|---|
| «Обʼєкти», місяці, послуги, послуги місяця (`EmptyStateView`) | 05a, 08e, 12e, 09e | `blueSoft2` |
| «Оберіть свою чергу» (`OutageMessage tone='power'`) | 20 | `powerOnSoft` |
| «Постачальник … не доданий» (`OutageMessage tone='muted'`) | 20c | `line` |
| «Немає інтернету» (`AccountDataOffline`, обидва варіанти) | 05o | `line` |

Кольори темної теми беруться з тих самих ключів.

## Як влаштувати ілюстрацію

```tsx
<View style={{ width: SIZE, height: SIZE }}>           {/* без фону й без overflow: hidden */}
  <PulseRings color='blueSoft2' size={SIZE} />         {/* першими — під колами */}
  <ThemedView backgroundColor='blueSoft' style={{ ...StyleSheet.absoluteFill, borderRadius: SIZE / 2 }}>
    <PulseCore>
      <ThemedView backgroundColor='surface' style={styles.tile}>…</ThemedView>
    </PulseCore>
  </ThemedView>
  <ThemedView style={styles.badge}>…</ThemedView>      {/* бейдж не анімується */}
</View>
```

- Кільця — першими дочірніми елементами контейнера без фону; кола ілюстрації лежать над ними, тож поки кільце менше за ілюстрацію, його не видно, а далі воно виходить за її межі до 135 %. Контейнер і батьки не обрізають (`overflow: hidden` не ставити).
- Не анімуються: бейдж «плюс» чи номер черги, заголовок, текст, кнопка.
- Пульсація — лише для порожніх станів з канвасу. Стани помилок (`OutageMessage` без `pulse`) і чек «Розрахунок — порожній» (11e) — без неї.

## Фокус і «Зменшити рух»

- Екран нижче в стеку не в фокусі — анімація зупиняється, щоб не витрачати UI-потік.
- При системному «Зменшити рух» кілець немає зовсім, плитка нерухома. Це свідоме відхилення від канвасу, де кільця лишаються статичними на повному розмірі (spec 008, FR-017).

## Як додати пульсацію новому порожньому стану

Обгорнути ілюстрацію за схемою вище, вибрати колір з таблиці (або додати рядок для нового стану) і, якщо стан не завжди порожній (як `OutageMessage`), увімкнути пульсацію пропом лише там, де це порожній стан з канвасу.
