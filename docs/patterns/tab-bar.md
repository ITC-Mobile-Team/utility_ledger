# Таб-бар

Таб-бар видно лише на кореневому екрані табу. Усі екрани, що відкриваються всередині «Обʼєктів» (обʼєкт, місяць, форми, вибір іконки тощо) і «Світла» (налаштування графіка), показуються без нього.

- Видимість рахує `src/app/(tabs)/_layout.tsx` з `useSegments()`: якщо активний маршрут глибший за `(tabs)/(objects)` або `(tabs)/(outages)`, `NativeTabs` отримує `hidden`.
- Екранам нічого робити не треба — новий маршрут у стеку `(objects)` чи `(outages)` автоматично буде без таб-бару.
- Сегменти змінюються одразу на початку переходу, тож таб-бар ховається під час push і з'являється під час повернення на корінь, без мерехтіння між вкладеними екранами.
