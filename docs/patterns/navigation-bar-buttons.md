# Кнопки навбару

Великі кнопки під заголовком навбару (`navigationBarButtons` у `NavigationView`) — наприклад «Додати адресу», «Архів», «Редагувати».

- Вигляд один для всіх екранів: біла картка, кругла іконка зліва, підпис справа (`NavigationBarButton`). Компактних плиток з іконкою над підписом не робимо.
- Ширина кнопки — **50% ширини екрана** (`FULL_BUTTON_WIDTH_RATIO` у `src/components/navigation-bar/constants.ts`), незалежно від кількості кнопок.
- Кнопки завжди стоять в один ряд. Якщо вони не влазять, ряд гортається горизонтально; на другий ряд не переносимо.
- Під час скролу контенту великі кнопки згортаються в короткі «пігулки» (`ShortNavigationBarButton`), які теж гортаються в один ряд.
