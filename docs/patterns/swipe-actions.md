# Свайп-дії та скидання з «Повернути»

Еталон — `src/app/(tabs)/(objects)/[objectId]/[month]/index.tsx` (скидання внесеного значення послуги). Так само зроблене видалення місяця в `src/app/(tabs)/(objects)/[objectId]/index.tsx`.

## Поведінка

- Дія над рядком списку відкривається свайпом уліво: `SwipeableRow` з `src/views/objects/swipeable-row.tsx`. Деструктивна дія — фон `coral`.
- Свайп є лише там, де дія має сенс: «Скинути» — тільки на рядках з внесеним значенням (показник, сума з рахунку, кількість днів). Решта рядків — без свайпу.
- Під списком, де є свайп, — підказка «Помилились? Проведіть ліворуч по послузі…».
- Перед дією — системний `Alert` з кнопками «Скасувати» та деструктивною дією. Для скидання — `confirmResetEntry` з `src/views/objects/confirm-reset-entry.ts`.
- Після скидання на екрані — `UndoToast` (««Світло» скинуто» + «Повернути»), ховається сам через 5 с. Перед скиданням беремо знімок запису з `ledger.getSnapshot()`, «Повернути» записує його назад.
- Та сама дія доступна без свайпу: на екрані редагування (`reading.tsx`, `amount.tsx`) — `TextButton` «Скинути…» під основною кнопкою у футері, у шторці днів — «Скинути значення». Звідти після підтвердження повертаємось назад без тосту.
- Для футера з `TextButton` передавай `useFormFooterKeyboardInsets(hasHint, true)`, щоб поле у фокусі не ховалось під футер.
