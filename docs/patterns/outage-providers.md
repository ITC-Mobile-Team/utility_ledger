# Графіки відключень і постачальники

Вкладка «Світло» (`src/app/(tabs)/(outages)/`) показує графік погодинних відключень для обраних черг. Дані беруться від постачальника (обленерго) міста, яке користувач обрав у налаштуваннях графіка.

## Як влаштовано

| Частина            | Файл                                          | Що робить                                                                                                                    |
| ------------------ | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Модель             | `src/services/outages/types.ts`               | `OutageProvider`, `OutageSchedule`, слоти по 30 хв: `on` / `off` / `maybe` (перемикання)                                     |
| Постачальник       | `src/services/outages/providers/*.ts`         | Завантажує й розбирає графік свого джерела в `OutageSchedule`                                                                |
| Реєстр             | `src/services/outages/registry.ts`            | Список постачальників, `getProviderForCity(city)`                                                                            |
| Логіка графіка     | `src/services/outages/schedule.ts`            | Проміжки вимкнень, статус «зараз», час у поясі постачальника, форматування                                                   |
| Налаштування й кеш | `src/services/outages/settings-repository.ts` | Місто, черги з назвами; останній графік кожного постачальника для показу без мережі                                          |
| Хуки               | `src/providers/outage-provider.tsx`           | `useOutageSettings`, `useOutageSchedule` (кеш → мережа, оновлення раз на 10 хв і при поверненні в застосунок), `useZonedNow` |

## Як додати місто

1. Створи `src/services/outages/providers/<id>.ts`, що експортує `OutageProvider`: `cities` — назви з `src/constants/cities.ts`, `queues` — усі черги постачальника, `timeZone`, `fetchSchedule()`.
2. Розбір відповіді винеси в окрему чисту функцію (як `parsePoltavaSchedule`), щоб її можна було перевірити на збереженій відповіді.
3. Додай постачальника в `outageProviders` у `registry.ts`. Місто саме переїде з «Незабаром» у «Доступно» у шторці вибору міста, а вкладка почне показувати графік.

UI нічого не знає про конкретного постачальника: назва, черги й посилання «Не знаєте свою чергу?» беруться з `OutageProvider`.

## Полтаваобленерго

- Джерело: `https://www.poe.pl.ua/customs/dynamicgpv-info.php` — HTML-фрагмент. На кожен опублікований день є блок `gpvinfodetail` з датою («4 листопада 2026 року») і таблицею `gpv-table`: рядок — черга, 48 клітинок з класами `gpv-s1` (світло є), `gpv-s2` (вимкнено), `gpv-s3` (перемикання).
- Перемикання стоїть одразу після вимкнення: світло можуть дати будь-якої миті до його кінця. Тому проміжок вимкнення має `end` (кінець гарантованого вимкнення) і `switchEnd`.

## Вигляд

- Навбар `barType='power'` (коричнево-золотий градієнт), підзаголовок — постачальник і час оновлення. Чипи обраних черг і «+» — у шапці під підзаголовком (`headerContent`), згортаються разом із заголовком.
- Кольори тільки з токенів `powerOn*`, `powerOff*`, `powerSwitch`.
- Стани: черги не обрано → заклик налаштувати; місто без постачальника → «Постачальник … поки що не доданий» і «Змінити місто»; день без графіка → «Графік на завтра ще не опубліковано»; немає мережі → показуємо збережений графік з приміткою, без нього — помилка з «Спробувати ще раз». Оновлення — потягнути вниз.
