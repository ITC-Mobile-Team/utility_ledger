# Spec Delta

## Purpose

Ряд чипів у шапці екрана «Відсутність світла», яким користувач перемикає графік між обраними чергами; зміна самого набору черг відбувається в «Налаштуваннях».

## ADDED Requirements

### Requirement: Ряд черг містить лише обрані черги
Ряд чипів у шапці екрана «Відсутність світла» SHALL показувати по одному чипу на кожну обрану чергу (номер і, якщо задано, назва) і MUST NOT містити інших елементів — зокрема кнопки «+» для додавання чи зміни черг.

#### Scenario: Обрано кілька черг
- **GIVEN** користувач обрав черги 1.1 і 3.1
- **WHEN** відкриває вкладку «Відсутність світла»
- **THEN** у ряду під заголовком видно рівно два чипи — «1.1» і «3.1»
- **AND** після останнього чипа немає кнопки «+»

#### Scenario: Обрано одну чергу
- **GIVEN** користувач обрав лише чергу 1.1
- **WHEN** відкриває вкладку «Відсутність світла»
- **THEN** у ряду видно один чип «1.1» і нічого поруч із ним

#### Scenario: Перемикання черги
- **WHEN** користувач тапає чип «3.1»
- **THEN** чип «3.1» стає обраним (білим), а графік показується для черги 3.1

### Requirement: Зміна черг через шестерню в навбарі
Екран «Відсутність світла» SHALL вести до зміни набору черг через шестерню праворуч від заголовка, яка відкриває екран «Налаштування».

#### Scenario: Користувач хоче додати чергу
- **GIVEN** користувач на вкладці «Відсутність світла» з обраними чергами
- **WHEN** тапає шестерню в навбарі
- **THEN** відкривається екран «Налаштування», де можна обрати або прибрати черги

#### Scenario: Повернення після зміни черг
- **GIVEN** користувач на екрані «Налаштування» додав чергу 2.1
- **WHEN** повертається на вкладку «Відсутність світла»
- **THEN** у ряду зʼявляється чип «2.1» поруч з іншими обраними чергами, без кнопки «+»
